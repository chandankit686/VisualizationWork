# Power BI Visualization Projects

Welcome to my Power BI visualization portfolio! This repository contains a collection of interactive dashboards built using Power BI to demonstrate my skills in data analysis, storytelling, and dashboard development. These reports are designed to offer clear insights through engaging visuals and DAX-driven interactivity.

## 📁 Project Files

Below is a brief overview of each `.pbix` file included in this repository:

### 1. 🚲 `Bike_sales.pbix`
- **Objective**: Analyze sales performance of various bike models.
- **Key Features**:
  - Region-wise and model-wise sales breakdown.
  - Monthly performance tracking for a selected quarter.
  - Highlights top-performing models and regions.

### 2. 💰 `marketing_spend.pbix`
- **Objective**: Visual comparison of marketing expenditure vs sales performance.
- **Key Features**:
  - Quarter-based analysis of marketing ROI.
  - Region-wise marketing spend and corresponding sales.
  - Identifies high-performing and underperforming regions.

### 3. 📦 `powerbi 2_report.pbix`
- **Objective**: Detailed order quantity analysis.
- **Key Features**:
  - Month-wise order volume tracking for a particular quarter.
  - Region-wise performance breakdown.
  - Enables operational insight into demand trends.

### 4. 📈 `time_series.pbix`
- **Objective**: Trend analysis using time series visualizations.
- **Key Features**:
  - Timeline visualizations for trend insights.
  - Identifies seasonal patterns and fluctuations.
  - Designed for long-term data perspective.

## 🔧 Tools & Techniques

- **Power BI Desktop**
- **DAX (Data Analysis Expressions)** for dynamic metrics and interactive visuals
- **Power Query** for data transformation
- **Interactive dashboards** with filters, slicers, and drill-downs
